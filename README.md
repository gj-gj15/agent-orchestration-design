# 智能体编排设计守则（agent-orchestration-design）

多智能体工作流编排的设计守则与评审框架：一主一验·多子临时、主 Agent 不当裁判、协查三支柱独立、实例即焚、证据带外、标准冻结、重试对症封顶、漂移过决策门。

## 结构

- `SKILL.md` — 技能入口
- `references/` — 参考文档

## 安装

- **通用 Agent Skill 平台（Claude / CodeBuddy / Cursor 等）**：将本目录放入平台的 skills 目录即可
- **TeleAgent / Octop**：导入本技能包后启用
